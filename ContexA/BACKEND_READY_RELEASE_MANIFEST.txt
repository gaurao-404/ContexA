Frontend: includes API request timeouts, visible backend/database health state, and submission-mode onboarding visibility guard.

Deployment: Cloudflare-free local demo and Render single-service paths are documented; production infrastructure still needs account-side configuration and live verification.
Local environment overrides, databases, uploads, bytecode, TypeScript build metadata, caches and node_modules excluded.
